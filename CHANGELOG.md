# Changelog

## 1.0.0 — 2026-09-20

Initial public release of Toshiba Modbus Monitor.

- Windows and Linux monitoring deployments.
- SQLite change logging, web dashboard and CSV export.
- Channel selection, live-card and category ordering.
- Persistent warning indicator independent of visible monitoring cards.
- PCM002Z parameter backup, import preview and guarded parameter writes.
- Windows system tray controller and offline CSV viewer.
