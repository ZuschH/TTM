# Changelog

## TMM Linux Master 1.3.0-rc3 — 2026-11-22

- Publish the feature-frozen Linux Master 1.3 release candidate for the final
  24-hour machine test.
- Classify all later 1.3 changes as Bugfixes and add the 1.4 roadmap.
- Exclude third-party Sequent PDFs from the MIT-licensed source and release;
  use official publisher links plus checksum-pinned optional downloads.
- Keep the Windows products at their separately released versions.

## 1.0.0 — 2026-09-20

Initial public release of Toshiba Modbus Monitor.

- Windows and Linux monitoring deployments.
- SQLite change logging, web dashboard and CSV export.
- Channel selection, live-card and category ordering.
- Persistent warning indicator independent of visible monitoring cards.
- PCM002Z parameter backup, import preview and guarded parameter writes.
- Windows system tray controller and offline CSV viewer.
